Mettez ici les photos des articles (format .jpg ou .webp, format portrait 3/4,
largeur conseillée 900 px, poids < 200 Ko).

Le nom du fichier doit correspondre à ce qui est écrit dans assets/js/config.js,
par exemple : robe-wax-1.jpg

Tant qu'une photo est absente, le site affiche automatiquement un visuel de
remplacement — rien ne casse.
